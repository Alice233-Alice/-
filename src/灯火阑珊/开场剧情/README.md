# 开场剧情写作入口

在本目录创建 Markdown 文件，文件名与开场正文首行方括号中的完整标题相同。例如正文以「【开局三-白清弦】」开头，对应文件名为「开局三-白清弦.md」。同一人物的不同开场分别写稿。

复制「_模板.md」后改名并填写，或直接自由写作。作者写定的事实、因果和人物动机应清楚表达；希望出现的场景与可变化的部分也可单独说明。模板、示例及 README 均不会激活，空文件同样跳过。

保存后，现有编译监听会把底稿打包到测试版相关产物中。运行时按当前聊天的开场标题读取，首次正常推演在准备阶段构思本局剧情，成功后保存在隐藏变量「$开场剧情」中。正常推演继续携带作者底稿与构思；重推复用已有构思，尚未准备时直接承接原稿。

修改底稿后，下一次正常推演会重新准备未来的铺陈，已有经历持续承接。删除底稿或清空内容后，对应开场停止注入作者剧情。首次规划失败时按原稿继续，之后的正常推演可再尝试。

首版在「灯火通明-测试版」的伪同层正文中使用。玩家自由寻途与作者剧情各自保存，结束追踪或清理玩家行旅不会删除作者底稿和本局构思。

发布时携带最新的测试版前端、伪同层控制器和变量结构产物。底稿作为构思资料使用，具体进展、线索与任务依实际正文通过原有 MVU 流程记录。
