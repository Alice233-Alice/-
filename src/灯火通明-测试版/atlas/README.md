# 三界 SVG 地图

`WorldMapCanvas.vue` 保持原地图组件的五个行踪属性，直接接收 MVU 数据。地图浏览、地域详情和跨界入口仅改变查看状态。

- `generated/`：地标索引、地域轮廓及预览控制器模块。绘图相关文件由
  `node output/svg-atlas-preview/export-frontend.mjs` 更新，不手改。原始绘图源保存在 `output/svg-atlas-preview/`。
- `assets.ts`：复用正式版的云端资源加载器，使用相同的发布提交、内容校验值和浏览器 HTTP 缓存。解压数据仅供当前打开的一界使用。
- `integration.ts`：将控制器挂载到独立 Shadow DOM，处理本地界域切换、定位标记及销毁清理。
- `camera.ts`：合并每帧的拖动/缩放输入，移动合成图层；停止操作后仅更新交互层。文字采用几何缩放，避免每个滚轮刻度重新生成字号。
- `artwork.ts` /
  `encoder.ts`：先显示约 200 万像素的可交互地形，再于空闲时逐层补齐约 1600 万像素的细节。地形直接绘制到显示 Canvas，省去大图 PNG 编码及再次解码；城郭和宗门先用原始 SVG 图像显示，再由临时 Worker 缓存。拖动或隐藏地图时暂停启动下一项细节处理，切界和卸载会取消等待、终止 Worker、释放画布及对象 URL。天空分层仍可独立淡出。导出 SVG 不含位图；若浏览器无法生成首屏缓存，恢复原 SVG 显示。
- `output/svg-atlas-preview/prepare-symbols.mjs`：打包时把城郭、宗门的绘图内容移入字符串，保留原定义 ID，避免首次开图先建立上万绘图节点又删除。全部路径、坐标和引用不变；独立 SVG 导出仍包含完整矢量图。
- `location.ts` /
  `placement.ts`：已有地标直接定位；新地点结合所属地域、方位、地形词及明确的邻近地标，在地域内稳定模拟落点，显示地点名与“约位”。五域范围与绘制轮廓共用
  `generated/geography.ts`。同名地点、同样线索可复现；不使用随机时间种子，不改写 MVU，也不把可用通道当作地理邻接。只知道地域名时仍为区域定位，连所属地域都未明时不强行落点。
- `layout.ts` /
  `embedded.css`：宽屏将行踪与地域索引放在左侧，图例和地域志放在固定右侧，地图保留中央画布；窄屏改用简短行踪栏、可展开的图层按钮与底部地志。父组件提供实际可用高度。主城名称与地域标题只在镜头停稳时调整最小可读字号。

地图压缩文件独立放在仓库根目录 `assets/atlas/`，由现有 GitHub 仓库的 `atlas-assets` 分支通过 CDN 分发。浏览器自动缓存，主界面就绪后空闲预取所在界域。更新绘图与发布流程见 [正式版地图说明](../../灯火通明/atlas/README.md)。地图入口保持当前酒馆 URL；天界默认展开天渊，可选择三霄及九霄全景。五座主城、三阶阵枢与五渊镜界细节沿用已确认版本。

普通地图页使用紧凑页头，宽屏合并导航与世界时钟，输入框继续可用。地界、幽界的默认 100% 总览按地理内容范围取景，省去装饰边框留白；“总览”和 Home 返回这一视图。原始 SVG 与独立预览的全画幅保持不变。

首次进入地图才创建组件；切去历程、修炼等标签时仅隐藏，返回复用当前界域、显示纹理、缩放位置与已打开详情。隐藏期间不按零尺寸重排地图；行踪跨界更新延迟到再次可见时处理。仅保留正在浏览的一界，切换界域或卸载整个前端时释放旧控制器与对象 URL，避免同时常驻三界纹理。

控制器的 `ready` 表示地图已可显示和操作，不等待全部高清缓存。`data-artwork="preview"` 为可用首屏，`cached`
为细节缓存完成，`inline` 为原 SVG 回退；调用方不能把后台缓存完成再次当成导航或重新定位的信号。

定位与跨界链接检查：`pnpm exec ts-node --files --project tsconfig.schema-test.json tests/bright-atlas.test.ts`。

性能复查必须覆盖真实鼠标输入、逐格滚轮停顿及松手后的重绘；仅用脚本派发事件、只统计手势进行中的帧，会遗漏字体排版和收尾重绘产生的卡顿。
