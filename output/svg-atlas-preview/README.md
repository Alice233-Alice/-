# 九野山海舆图 · 独立 SVG 预览

- `index.html`：地界卷，精细蚀刻地形、五域独立城郭、宗门驻地与九野阵网；地界、幽界可缩放至 1200%，天界保持 600%；支持拖动、点选地志。
- `underworld.html`：幽界卷，绘制五渊地形、层级与遗迹，并以独立附图展示倒悬天墟的五渊逆像。顶部可切换地界、幽界；地表入口详情可直接跳转到对应渊域。
- `sky.html`：天界卷，以斜侧视角展开下霄、中霄、上霄；顶部可在九霄全景和三层近景间切换，其余层淡出。点选遗迹和入口可查看地志、放大细部。
- `sky-atlas.svg`：完整的九霄悬天长卷，横空天渊、环聚残宫、飞舟、龙凤遗骨、罡风雷海及法则断纹全部为 SVG 路径；三霄不画泥石陆基。
- `sky-data.mjs` / `sky-engraving.mjs` / `generate-sky.mjs`：分别保存天界地志、细部绘图函数和画面排布；三霄中含天渊、星陨废墟、太古战场、天道裂隙 4 个独立详情区，11 处遗迹与分景、5 处通路入口。
- `sky-rift.mjs`：天渊空间裂口与剪切流纹、星辰冢、古战场遗痕、渊核断口、下垂星流和九天罡风雷海。天渊是下霄的主构图，废墟环聚两侧，顶部「下霄 · 天渊」直接聚焦这一层。
- `underworld-atlas.svg`：幽界五渊的完整独立矢量图，含五处地表入口、五处极底逆泉、九口轮回井、33 处可点选的层级与地标。
- `generate-underworld.mjs` / `underworld-data.mjs`：幽界地形绘制与世界书地志；岩壁皴线、残剑、根须、古迹与熔岩裂流均使用矢量路径。
- `underworld-layout.mjs`：五渊、入口、逆泉与镜面附图的分区排布；岩壁互不相交，地标使用引线标注，缩放时按可用空间显示标签。
- `underworld-etching.mjs`：岩层细纹、矿石刻痕、根瘤菌褶与黄泉石砌建筑的细部绘制。
- `shanhai-atlas.svg`：完整独立矢量地图，不含位图、外链图片或 Canvas。单独打开 SVG 可查看静态地图；交互在 HTML 预览中运行。
- `generate-relief.mjs`：当前地图生成源。连续高程场、33 层等高线、11,157 条坡面皴线、1,392 个海岸节点、林冠与微型城郭均生成为 SVG 路径。
- `region-outlines.mjs`：五域共用山麓、林缘分界并复用原图海岸，悬停淡显，点选后以淡金铺色和细线勾勒地域；范围为地形意绘。轮廓保留在轻量交互层，地名点击区保持透明。
- `preview-shell.html`：交互预览外壳。
- `capitals.mjs`：五种独立建筑形制，包含重檐瓦脊、墙砖垛口、街坊院落、桥梁和区域专属建筑；主城图标可点击放大查看。
- `capitals-study.svg`：五座主城的矢量细部对照图。
- `sects-data.mjs` / `sects.mjs`：从《宗门势力概览》读取 30 处势力的教义与说明，配置 26 处地界、4 处幽界的示意坐标与各自山门图符。总览隐藏，放大后先显点位与名称，再显示殿院、药圃、矿庄、浮岛、林地或行舟；名称保持可读字号并避让已有地名。宗门入口可单独开关，桌面索引可直接聚焦。
- `transport.mjs`：5 处域间星枢、6 处境道官阵、3 处隐界暗桩示意，以及三种不同阵纹与分层阵路。可以分别开关阵阶、点选高亮连线，并查看耗材、时标、盘查和异变影响。
- `atlas-data.json`：地界地域志与跨界入口说明。
- `generate.mjs`：当前版本的生成入口，一次更新地界、幽界、天界和城郭细览。

重新生成当前版本：

```sh
node output/svg-atlas-preview/generate.mjs
```

启动本地预览：

```sh
node output/svg-atlas-preview/serve.mjs
```

浏览器访问 `http://127.0.0.1:5187/`。本地服务仅监听本机。

地图取材于灯火阑珊世界书。地形与城池位置为示意，非精确里程图；地界、幽界与天界分别成卷，顶部可互相切换。

宗门布点遵循概览中明确的所属地域与地形关系，不从政治影响范围推导占地面积。赤霄阁位于雷暴海，浮云朝露阁表现为东苍地界浮岛，海底宗门用海面投影表示。渡厄幽帆、彼岸提灯人和未定驻地的无间轮回道标为活动示意；不据此添加世界书设定。山门绘制尺度小于主城，随地图等比缩放，但图符为辨识而放大，不具备精确里程或用地比例。现有地点定位可识别宗门名称，并明确显示约位。

静态导出的地图仍为纯 SVG；交互界面将不可变建筑绘制到一个共用图集，保留名称、命中区域和轻量动态层。图集只在展开时准备，拖动及连续缩放不重绘宗门建筑；标签在手势结束后整理。

天界预览：`http://127.0.0.1:5187/sky.html`。以 2026-09-22 最新《九霄天界（上中下霄）》《世界空间结构》《天渊》为依据。下霄的天渊是长三万里、宽逾百里的主轴天堑，废墟受引力撕扯环聚其侧；中霄龙凤万丈骸骨直接横卧虚空；上霄高度为八至九万丈。图中没有泥石浮岛底座，刻度、空间裂口形状、骨骼造型与透视远近均为意绘，不按比例。

天界通路保留下霄至中霄的朔日涟漪时窗；寂静黑孔依最新设定直通上霄，以实线标示。天渊有罡风乱流层、星辰冢、古战场遗痕与渊核断口四重险境，分别可点选。地界垂落口通西庚极西与潮音海；渊核断口对映倒悬天墟·沉星渊薮，上霄逆奇点潜通阴界·逆规奇点，链接打开倒悬天墟总图及九霄沉渊说明，并保留入界门槛。天渊与归墟仅说明遥相共振，不画成直连通路。九霄仍属于凡界，未将尘封绝天古阵画为可用路线。

天界使用与幽界一致的独立详情区域；窄屏入口使用短注记，主标题与地标标签按实际显示尺寸调整字号，细部标签自动避让。静态 SVG 保留全部注记，交互标签、分层淡出和视图缩放由预览页管理。

幽界卷依据五渊条目、《世界空间结构》及《倒悬天墟·五行逆反界》绘制。图中岩壁、洞窟、火品环层与遗址布局为艺术意绘，不代表等距深度或唯一坐标；仅标示世界书明确的下潜入口，不增设五渊之间的直连通路。倒悬天墟是三界阴面的镜像虚空，作为独立附图呈现，保留元婴境或至宝护体、异变薄弱期或特殊秘法等入界条件。

幽界详情在桌面使用独立侧栏，在窄屏使用底部面板，均占据自己的布局空间，不覆盖地图。全图优先显示渊域与门户；放大、悬停或选择地标后按标签间距显示细部注记。

传送阵阶、五域中枢、海关节点、时标及耗材依据 `[地图] 九野通衢·寰宇阵枢.yaml`。城郭建筑形制、节点短名与示意连线为视觉设计；世界书未固定暗桩坐标，因此暗桩明确标注为位置或类别示意，不增设固定地点或唯一的直连拓扑。主城星枢绘于城侧只是标记排版；尘封的绝天古阵仅保留为传闻，不画成可用跨界航路。

当前三界地图已接入 `src/灯火通明/components/WorldMapCanvas.vue`。本目录仍可独立预览；酒馆前端随包携带压缩后的三界 SVG，不依赖本地预览服务。

三界生成器统一通过 `optimize-svg.mjs` 精简路径写法，再由导出器进行 gzip 压缩。路径坐标采用一位小数的适度有损精度，绘图属性（透明度、线宽、圆点半径等）保留三位小数；已对照总览和高倍放大的城郭、山脊、岩壁与天渊建筑。极细边缘可能有轻微位置差异，但不降低纹理密度、不合并图形节点、不更名或删除运行时使用的 ID、class、data 属性。幽界只生成其镜像绘图需要的 `capital-imperial`，其余四座主城仅在地界保留。新增动态图形时应同时检查详情面板的引用，不能只根据静态 `<use>` 判断定义是否有用。

宗门概览读取兼容旧式“名称：【定位】说明”和新版“名称【定位】：说明”，括号别称沿用原地图 ID。概览移除的宗门不再生成标记；新增宗门仍需补齐坐标与建筑后才能导出，避免静默漏项。

运行 `node --test tests/atlas-svg.test.mjs` 检查图形定义、交互属性、引用完整性和前端压缩资源；地图定位回归使用 `pnpm exec ts-node --files --project tsconfig.schema-test.json tests/bright-atlas.test.ts`。

修改绘图或预览控制器后，运行 `node output/svg-atlas-preview/export-frontend.mjs`，一次重新生成最新 SVG、独立预览及 `src/灯火通明/atlas/generated` 中的前端资源，然后按原项目流程构建前端。导出器复用预览控制器，编译成普通模块；实际界面在 Shadow DOM 内挂载当前一卷，隔离地图样式并在切换时清理观察器与事件。
