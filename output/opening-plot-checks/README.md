# 开场剧情实施与验证

## 作者入口

底稿目录为 `src/灯火阑珊/开场剧情/`。复制 `_模板.md` 并按开场标题改名，例如 `开局三-白清弦.md`，随后自由填写剧情。`_写法示例.md` 提供独立虚构的写作示例；下划线文件和 README 都不会激活。

底稿通过 Webpack 已有的原文加载规则收集，复用当前实时监听。首次测试版伪同层正文推演在准备阶段构思本局剧情，成功后存入 `$开场剧情`。之后的正常正文携带作者稿与本局构思，重推复用已有构思；没有缓存时沿原稿展开。底稿修改会在下次正常推演重新准备未来铺陈。

作者原稿中的事实与动机持续承接，实际进展依旧由正常正文及 MVU 记录。缓存与玩家行旅分别保存，清理指定玩家行旅会保留作者构思。
