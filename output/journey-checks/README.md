# 寻途与行旅验收记录

实施位置：`src/灯火通明-测试版`。共用 MVU 结构及伪同层控制器承接必要的数据与提示词处理。

## 使用入口

正文末尾点击「寻一段远途」，或打开「行事」中的「寻途与行旅」。可填写偏好或选取灵感方向，每次生成三个长篇提案。

选定后记录行旅意向与后台构思，依现有行动偏好填入输入框或发送起念。之后可以续行、暂歇、结束追踪与翻看历次行旅。正文发生的实际进展由 MVU 维护；线索、纪事和猜想保存于对应楼层快照。手札支持关联线索、记录猜想及填入核实行动。

已保存行旅的每条记录提供「清理记录」，确认时显示所选行旅名称。仅删除该行旅、手札与对应后台蓝图；清理当前追踪项时同时取消追踪。其他行旅、任务、世闻及旧楼层快照保留。结束追踪继续只取消关注。

`preview.html` 使用测试版实际组件和主题渲染样稿，页面中的示例互动只修改本地样稿资料。
