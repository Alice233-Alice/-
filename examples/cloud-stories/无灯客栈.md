# 固定核心

雾岭驿道旁的归客栈被一盏失去灯芯的引魂灯困在旧夜。十年前，掌柜沈蘅为等遭山崩掩埋的弟弟，借守灯人的术法留住最后一班归客。她取走登记簿上每一位新客的名字，替亡者补足回家的路。客栈收集的是被自愿交出的名字与归愿，力量有明确边界：拒绝登记、保留自我称谓、结伴核对记忆，都能减弱其影响。真相始终保持，调查途径随玩家行动生长。

# 人物动机

沈蘅留在前台，温声招待，盼弟弟循灯归来。她知道旅客会逐渐忘记自己的来处，始终避谈名字的代价，仍可能因证据和劝说动摇。她能够移动登记簿与熄灭客房灯火，无法任意抹杀未登记者。

守夜童子阿砚是最后一名送信人的残留记忆，只会复述信中确实写过的话。他想把一封未送到的家书交给收信人，可以通过字迹、日期及物证核实身份。亡者保留生前的思念与片段记忆，知情范围受各自经历约束。

# 关键节点

## 一：空桌添筷

玩家接触到客栈入口的传闻或邀约后，可自行决定探访。入栈后，空桌上的碗筷随客人报出名字而增加；门外脚印往返重合。让玩家亲手比较登记前后的变化，获得第一个可重复验证的异常。拒绝住宿、留在门外观察或询问旧路人，都能接触同一因果。

## 二：无名的家书

调查旧客房、灶房或驿站记录，可发现家书与十年前山崩的日期。失去名字的客人认得家乡物件，却说不出自己的姓氏。阿砚的话与纸上字迹能够交叉查证。玩家应有机会找出名字与记忆受损的联系，并获得保护自身或帮助同行者的办法。

## 三：灯底旧骨

沿灯油、旧路标或山崩遗物追索，确认沈蘅的弟弟早已遇难，引魂灯用新客的名字维持等待。核心证据至少提供两条可行取得路径，避免单一物件卡死调查。掌柜的隐瞒、盼望与代价在证据支持下显露。修为高者可凭神识或术法调查，仍需面对归愿与名字之间的因果。

## 四：最后一班归客

证据充分后，玩家决定处理登记簿、引魂灯和亡者的归愿。可交涉、寻替代术法、护送残念或强行破局；行动的成本、效果和风险须事先给出可感知依据。玩家临时离开时保留已发生事实，客栈的变化通过合理渠道显露。

# 可调查线索

登记簿的新墨会渗入灯座，未登记者的笔迹保持原状。旧客记得家乡童谣的旋律，姓名所在的歌词一片空白。家书所写桥名与现存驿图相合，收信人姓名在信封夹层留有压痕。灯底埋着的铜铃与山崩记录中失踪者的遗物相符。每条线索都要经玩家实际观察、询问或查证进入手札，传闻保留待证性质。

# 两种收束

送归：玩家核实死讯，帮助亡者找回名字并完成送信或归葬的承诺，沈蘅自愿交还登记簿中的名字，引魂灯熄灭。客栈留在真实的驿道上，后续可有修缮、探望与守灯人的余波。

断灯：玩家确认取名机制后，保护被困者并切断登记簿与引魂灯的联系，使困夜瓦解。根据准备程度，可能救回多数名字，或留下部分需要后续寻回的记忆。掌柜承担其行为的结果，结局承接玩家此前的交涉与处置。

# 允许调整

入口位置可迁入玩家当前地域的山道、边镇或驿站，相关地名与入局时机随既有正文调整。玩家的修为、同行者和行事方式影响调查手段及处置代价。已经存在的关系和承诺持续有效。四个节点保留核心因果，可随有效行动合并或改换取得路径；每轮只推进实际触及的部分。

# 气氛与知情

用多出的一副碗筷、渐渐消失的门牌字迹、隔墙停住的童谣制造恐惧，让可验证的规则逐步浮现。未来异象、掌柜真相与结局条件保留在幕后。尊重玩家的拒绝和绕行，故事可在玩家愿意时推进。
