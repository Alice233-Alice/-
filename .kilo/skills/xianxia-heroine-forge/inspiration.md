## 三、能力与性情的映照

格式：能力 → 映照的性情。

- 越说谎越强的言灵 → 一个渴望说真话却不敢说的人。
- 能借他人五感一日 → 孤独，想知道别人眼中的世界。
- 治愈他人即承接其痛 → 自我牺牲，也藏着一点自毁倾向。
- 只能在月下出剑 → 白日里的软弱与夜里的锋利。
- 一言既出天道必应，违者反噬于己 → 极重诺，也极怕许诺。
- 能看见每个人身上的因果丝 → 早已看淡人情，偏有一根丝看不透。
- 情绪化为天象（怒则雷，悲则雨） → 被迫学会喜怒不形于色。
- 以记忆为薪炼器，越珍贵的器越要烧掉越珍贵的回忆 → 一个越来越空、却越来越强的人。
- 每蜕一次皮修为便进一层，旧皮里留着旧日性情 → 她在乎的东西会随修为一层层换掉，她自己也怕。
- 香道入阵，闻香者皆入其心境 → 她难以对人隐瞒，心事全写在气味里。

## 十一、命名

- **姓**：取意象与家世相符者。复姓宜少而精（南宫、上官、慕容、司空、闻人、公孙、钟离）；单姓可偏冷门（沈、阮、虞、谢、裴、薛、颜、殷、卫、姜、岑、晏）。
- **名**：一字为骨，一字为韵。避开“雪、冰、霜、月、梦”滥用；可取器物（簪、砚、灯、弦、笙）、节候（霁、霜降、惊蛰）、草木（蘅、芷、蓼、荇）、动作（迟、听、挽、拾）。
- **法号尊号**：职分＋意象（浮玉殿主、忘机剑尊），或一句诗截取。
- **检验**：念出声是否顺口；与现有红颜是否同字同韵；是否落入网文俗名。
