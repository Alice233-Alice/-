# 古风红颜与修仙设定构思法

本技能专管“想得出、想得好”。格式照搬仓库已有文件即可；这里教的是如何把一个模糊念头，长成一位立得住、玩得久的红颜，或一条能生出剧情的修仙设定。

灵感素材（反差配方、妖性本能、身份空位、信物、阻力、命名、门规等）见同目录 `inspiration.md`，卡壳时取用。

## 一、心法

1. **一人一钩**：每位红颜都要有一句话说得清的记忆点。听完这句，便能想见她的模样，也能想见她会惹出什么事。
2. **反差有根**：人前人后的落差，须由经历、血脉、誓约或职分逼出来。有根的反差才耐看，无根的反差只是人设拼盘。
3. **能力即性情**：道体、灵根、血脉、本命器、紫府心象，都是她心性与伤口的外化。换掉她的性格，这份能力也该随之失去意义。
4. **设定必生事**：每条设定落笔前先问：谁会因此得利、受苦、争夺、误会？答不上来的设定，删去或改写。
5. **情进有因**：爱意每进一步，都要靠事件推动，都要她付出或放下一点东西。

## 二、新红颜构思九步

### 第 0 步　查空位

- 先读 `红颜索引.yaml`，弄清已有红颜各占什么位子（师尊、瑞兽、器灵、神女、女帝、大师姐、圣女、魔女……）。
- 新角色至少在两项上与现有红颜错开：身份位、情感模式、与 `{{user}}` 的权力关系、种族形态、核心反差。
- 仿索引体例写出她的一句话定位（二三十字）。写不出，说明念头尚未成形，回到第 1 步。

### 第 1 步　找种子

不必从“姓名、境界、灵根”起笔。任选一个入口起念：

- **一个画面**：雨夜当铺里，替人估量魂魄成色的女掌柜。
- **一个矛盾**：执掌刑律之人，偏偏最想破一次戒。
- **一件物**：一盏她守了三百年、从不肯点燃的灯。
- **一种副作用**：越替人疗伤，自己越健忘。
- **一个处境**：寿元只剩三载的天才，被派去镇守一座须守百年的阵。
- **一种妖性**：鹤须起舞求偶，狐须拜月，蛇须蜕皮。

挑出最有张力的一颗，连问三次“为什么会这样”。第三层的答案，通常就是她的来历。

### 第 2 步　立三层骨

- **表**：人前模样。身份与职分加给她的言行规矩。
- **里**：私下或情动时的模样。被规矩压住的那一部分。
- **底**：表里为何分裂。一道旧伤、一桩誓约、一种血脉本能、一份推不掉的职分。

再定一处**破绽**：表层在何种情境下会漏出里层。破绽是互动最好写的地方，务必落到身体反应或小动作上。

> 檀织烟算盘落空，仍从容添茶，唯耳后浮起一层热意，眼底记下账本。
> 白清弦斥徒“成何体统”，目光先一步偏向侧旁，耳根漫红。

若角色带亲密侧写，隐癖须与“底”同根，并随阶段逐级解锁。羽岚骨韧肉实，寻常抚弄如隔靴搔痒，故渴求重手；三百年在长风里没个着落，故想被绳结系牢。私室描写本身交 `r18-fiction-writer`。

### 第 3 步　能力五问

为核心能力（道体 / 灵根 / 血脉 / 本命器 / 紫府心象）逐一作答：

1. **来源**：生来、夺来、换来、受赐，抑或受诅？
2. **功能**：能做什么。写成两三个能直接上场的用法。
3. **边界**：做不到什么。至少一条硬限制。
4. **代价**：每用一次付出什么（神识、寿元、情绪、记忆、体温、因果、容貌）。
5. **征兆**：施展时旁人看得见的异象（瞳纹发烫、发色转深、鸣珠急响、剑脊低鸣）。

末了补一问：**这份能力如何映照她的性情？**

> 映情体纳众生七情化为剑气，正配檀织烟爱看恶徒破防跳脚。
> 虚灵根“纳而不满，折而不破”，正配羽岚“纳天地暴烈，还岁月平和”之道。

接线规矩：

- 境界与职位对照 `境界威能.yaml`、`[规则] 宗门阶位与职级约束.yaml`，切莫给偏远小派弟子安渡劫修为。
- 高阶红颜参照 `大能约束与护道边界.yaml`，想好她在凡界如何收敛、出手留下何种余波。
- 妖族以血脉为本（云雀一族例外），血脉须写明功能与边界。
- 居地、宗门按地图落位，先挂靠五域与既有势力，再新增。

### 第 4 步　来历只写“那一刀”

- 只写一两件决定性事件，每件都改变了她的某种选择习惯。生平流水账留给 AI 补。
- **秘密分三层**：人尽皆知 / 亲近方知 / 唯深爱期肯说。每层对应一个阶段解锁。
- **留一笔未了之事**：仇家、旧约、未解封印、寻而未得之人、欠下的一份因果。这是长线剧情的引线。

### 第 5 步　为何是 `{{user}}`

- **相遇有机**：职责交集、利益交换、意外牵连、同困一境。她只做合乎身份的事，切勿为制造相遇让她跑去做外行之事。
- **不可替代之处**：她在 `{{user}}` 身上看见了什么别处寻不到的东西？一种能力的共鸣、一处恰能容她卸下规矩的位置、一份对她身份的不在乎、一种被需要的感觉。“被人格魅力吸引”“第一眼便觉亲切”一类说法一律弃用。
- **初始权力关系**：她在上、在下、平起平坐、互有所求。情感推进往往就是这份权力关系的翻转或消融。
- **称呼**：初始称呼，以及何时、因何改口。

### 第 6 步　埋种子

设一到三颗贯穿全程的种子：物、声、约、习惯、禁忌。每颗都规划“埋下、变化、兑现”三步。

> 羽岚腰间旧红绳：陌生期只是佩了数百年的旧物；确认期她亲手解下，把绳头奉到公子掌中。

种子是阶段人设之间最结实的线，宁少勿滥；埋下的必须回收。

### 第 7 步　五阶段弧线

区间沿用项目惯例：陌生 0-40 / 好感 41-80 / 心动 81-120 / 确认 121-160 / 深爱 161-200。阶段名可自拟副题，主名保留脚本能识别的字样（陌生、疏离、好感、留意、心动、确认、情定、深爱）。

先为每阶段写一句“本阶段她新学会或新失去的一件事”，再展开：

- **陌生**：规矩俱在，破绽偶现。埋下种子。
- **好感**：第一次为 `{{user}}` 破一条小规矩，事后自己也说不清缘故。
- **心动**：内心冲突最烈，表层规矩开始反噬她自己。最该写得好看的一段（参照 `3白清弦-心动期.yaml`：用行动写矛盾，冷脸、挑刺、深夜独坐、一杯凉茶饮尽）。
- **确认**：名分落定，种子兑现；同时引入新的外部阻力（身份、宗门、寿元、劫数、旧敌），免得关系停滞。
- **深爱**：核心性情依旧在场，只是全然朝向 `{{user}}`。她仍有自己的道途与骄傲。

铁律：

- 核心性格贯穿五阶段，变的是表达方式。白清弦到深爱期，开口仍是严师口吻。
- 确认、深爱两阶段最易写成同一种温顺依恋。各自保留一个只属于她的棱角或小麻烦，换个名字便不成立，才算写对。
- 每阶段给一个“转阶段事件”示例，说明她因何而变。
- `【阶段解析】` 只讲事，`【心音暗吐】` 只讲心，两段勿复述同一经过。
- 妖类红颜须把原形、本能、居地、生计写进场景。

### 第 8 步　可玩性

- **她自己的事**：没有 `{{user}}` 的这个月，她在忙什么？
- **三个主动场景**：邀约、求助、挑衅、考验、闯祸，由她发起。
- **两条底线与一处逆鳞**：她必定拒绝的事，以及碰了会真动怒的地方。
- **一处摩擦点**：可误会、可争执、可小醋，但守住项目之约（红颜之间不倾轧，既有情缘不由第三方改写）。
- **一根连线**：与某位现有红颜或 NPC 的关系一笔（同门、旧识、宿敌宗门、曾受其恩），让世界连成网。

### 第 9 步　视觉锚点

定三到五个不可变锚点（发色、瞳色、标志饰物、体态、衣色），并写一句锚点与性情的关联。生图提示词交 `image-prompt-writer`。

## 三、修仙设定构思

适用于体质、灵根、血脉、功法、神通、法宝、宗门、地点、秘境、天地机制。

**通用四问**

1. **规则**：一句话说清它如何运作。
2. **代价与漏洞**：谁付代价，谁钻空子。
3. **利益链**：谁守护它，谁觊觎它，谁因它受害。
4. **可感知**：凡人与低阶修士看见、听见、闻到的是什么。

**分类要点**

- **体质 / 灵根 / 血脉**：天赋与缺陷成对出现，缺陷要能化为剧情（月圆反噬、情绪失控、须某物压制、引来觊觎者）。
- **功法 / 神通**：写修炼门槛与心性要求（此法须心无挂碍；此法越恨越强）。招式写“效果＋限制＋征兆”，名取意象。
- **法宝 / 本命器**：来历一句；若有器灵，性情一句；与主人的关系一句。
- **宗门势力**：立场、财源、最古怪的一条门规、内部两派之争、与邻宗的恩怨。门规最能见宗风。
- **地点 / 秘境**：一条规矩（入此地者须……）、一种危险、一则传闻、一样唯此处可得之物。
- **天地机制**：触发条件、表现、波及范围、可被谁利用。

新设定须先挂靠既有地图与势力，名词风格向现有世界书看齐；新增势力与地点要能接入红颜的来历或未了之事。

## 四、反模板清单

- **标签代人**：只写“清冷、温柔、傲娇”，没有一个具体行为。
- **美貌静态堆砌**：外貌描写与身份、气质、关系张力无关。
- **名头无用**：神体、血脉、上古传承写了一长串，剧情里从不起作用。
- **战力膨胀**：境界高到 `{{user}}` 只能旁观，又无收敛之由。
- **动机悬空**：好感来得没有事件。
- **后期同质**：确认、深爱两阶段百依百顺，与别的红颜互换名字也成立。
- **身位撞车**：与现有红颜的身份位或情感模式重叠过半。
- **时间厚重滥用**：动辄“万载、千年、亘古”。
- **对白报菜名**：逐件列货、逐项报价；或为凑相遇硬安提问。
- **现代词与网文俗名**：情绪价值、边界感；霸天、傲雪一类。

## 五、协作方式

1. **公子只给模糊念头时**，先回三个方向。每个方向含：一句话定位、核心反差（表 / 里 / 底）、钩子能力、与 `{{user}}` 的缘起、一颗种子。请公子挑选或混搭。
2. **方向定下后**，交一份“构思卡”：九步要点逐条落实，用普通段落展示，勿用 YAML 代码块。
3. **构思卡确认后**，照仓库同类文件落笔。格式参考：
   - 总人设：`红颜/羽岚/羽岚人设.yaml`、`红颜/檀织烟/檀织烟人设.yaml`、`红颜/白清弦/白清弦人设.yaml`
   - 阶段人设：`红颜/羽岚/1羽岚-陌生期.yaml`、`红颜/白清弦/3白清弦-心动期.yaml`
4. **少读多想**：成文前只读 `警钟长鸣.yaml`、`半文言文风指南.yaml`、`红颜索引.yaml`，以及与本角色相关的一两份地图、势力条目和一份同类型参考人设。变量、脚本、initvar 与构思无关，一概不碰。
5. **原设为先**：公子已有设定一律保留；遇冲突先指出，再给兼容方案。

## 六、交付前自检

- 一句话定位，能否让人立刻想见她？
- 表 / 里 / 底是否因果相扣？破绽是否落到具体动作？
- 能力五问是否齐全？能力是否映照性情？
- “为何是 `{{user}}`”是否答到具体事件或特质？
- 种子是否有埋、变、兑三步？
- 五阶段的变化是否都有事件支撑？后两阶段是否各有棱角？
- 她是否有自己的目标与主动场景？是否与现有红颜错位？
- 文风：无破折号，无先否后肯的折转句，无“不X不X”四字连用，无冗余过渡词，无现代词。
